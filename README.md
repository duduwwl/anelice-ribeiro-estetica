# Anelice Ribeiro Estética

Site institucional e agenda de cuidados faciais para Anelice Ribeiro Estética, em Lavras/MG.

## Páginas

- `dist/index.html` — apresentação e serviços
- `dist/agenda.html` — agenda pública
- `dist/gerencia.html` — área de gerenciamento com senha de teste `anelice2026`

O agendamento deste protótipo usa o armazenamento local do navegador.
